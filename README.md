# 26센터 관리비 청구 자동화

Next.js 웹앱 (Vercel 배포용)

| 페이지 | 내용 |
|---|---|
| `/electric` | 한전 고지서 스캔 → 당월요금계·가산금·연체료·당월사용량 판독 → 총금액 = 당월요금계 − 가산금 − 연체료, 단가 = 총금액 ÷ kWh |
| `/water` | 상하수도 고지서 스캔 → 상수도·하수도·물이용부담금 단가 = 요금 ÷ 사용량 |
| `/expense` | 월별 경비내역서 입력 (전월 이월금액, 관리비부과항목별 합계, 감사/회장 결재란, 인쇄, CSV 저장) |

## 고지서 판독
스캔 이미지를 Claude API(`claude-opus-5-5`)로 읽어 각 금액과 그 위치(색 상자)를 보여줍니다. 값은 화면에서 고칠 수 있고, 스캔 없이 직접 입력해도 계산됩니다.

## Vercel 환경변수
- `ANTHROPIC_API_KEY` (필수, 판독 기능)
- `ACCESS_CODE` (선택) 설정하면 판독·서버 저장을 쓸 때 접속코드를 한 번 입력해야 합니다.
- `KV_REST_API_URL`, `KV_REST_API_TOKEN` (서버 저장) Vercel > Storage 에서 Upstash for Redis 를 프로젝트에 연결하면 자동 설정됩니다. 없으면 브라우저에만 저장됩니다.

## 개발
```
npm install
npm run dev
```
