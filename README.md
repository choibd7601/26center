# 26센터 관리비 청구 자동화

Next.js 웹앱 (Vercel 배포용)

| 페이지 | 내용 |
|---|---|
| `/electric` | 한전 고지서 스캔 → 당월요금계·가산금·연체료·당월사용량 판독 → 총금액 = 당월요금계 − 가산금 − 연체료, 단가 = 총금액 ÷ kWh |
| `/water` | 상하수도 고지서 스캔 → 상수도·하수도·물이용부담금 단가 = 요금 ÷ 사용량 |
| `/expense` | 월별 경비내역서 입력 (전월 이월금액, 관리비부과항목별 합계, 감사/회장 결재란, 인쇄, CSV 저장) |
| `/meeting` | 총회(관리단집회) 준비: 정기·임시총회 단계별 절차·필요 문서·주의사항, 통지 기한(1주) 점검, 정족수(사람 수+면적) 계산, 소집통지서·공고문·의안 설명서·위임장·서면결의서·소집 청구서/동의서·공유자 대표자 지정서·참석자 명부·의사록·결과 공고문 생성(인쇄/PDF, Word 저장) |
| `/records` | 집합건물 회의관리: 관리단집회(정기·임시)·관리위원회·기타 회의를 회의별로 서버에 저장하고 목록(종류·연도·검색, 휴지통)으로 관리. 참석자·출석, 보고·의결 안건과 찬반 수(가결 자동 판단), 첨부 서류, 후속조치 기록. 의사록(회의록)·참석자 명부·결과 공고문·의결사항 이행 점검표·서류 보관 표지 인쇄/Word 저장. ‘총회 준비’ 입력값 가져오기, 확정 시 잠금, 이전 버전 되돌리기 |

## 고지서 판독
스캔 이미지를 Claude API(`claude-opus-5-5`)로 읽어 각 금액과 그 위치(색 상자)를 보여줍니다. 값은 화면에서 고칠 수 있고, 스캔 없이 직접 입력해도 계산됩니다.

## Vercel 환경변수
- `ANTHROPIC_API_KEY` (필수, 판독 기능)
- `ACCESS_CODE` (필수) 사이트 비밀번호. 이 비밀번호로 들어와야 보고 저장할 수 있습니다.
- `NEXT_PUBLIC_IDLE_MINUTES` (선택) 입력이 없을 때 자동으로 잠그는 시간(분), 기본 30. 잠그기 전에 입력 내용을 먼저 저장합니다.
- `KV_REST_API_URL`, `KV_REST_API_TOKEN` (서버 저장) Vercel > Storage 에서 Upstash for Redis 를 프로젝트에 연결하면 자동 설정됩니다. 없으면 브라우저에만 저장됩니다.
